# 👨‍💻 Aaron Roethe

Software engineer on the integrations team for a public-safety records management platform. I build and run the pipelines that import data into and export data out of the platform, and I spend a lot of time on making them recover by themselves when they break.

Since 2022: ~680 pull requests (~530 merged) across Go services, Terraform, Kubernetes deploy configs, and observability tooling.

### 🔧 What I work on

- **Integrations framework:** Go and C# services for importing and exporting data, including workflow orchestration and data-mapping templates.
- **Self-healing pipelines:** a self-healing DLQ tool that retries failed messages and sends notifications for anything it can't resolve.
- **Infrastructure & delivery:** Azure infrastructure in Terraform (Function Apps, Event Hubs, App Insights diagnostics), GitOps deploys on Kubernetes with ArgoCD, and release-branch / cherry-pick tooling.
- **Observability & on-call:** Grafana dashboards and Prometheus alerts, Splunk searches, and per-alert runbooks.
- **Testing:** end-to-end API test suites (Karate) for integration flows.
